🌦️ WeatherSphere:
WeatherSphere is a modern and responsive weather dashboard built using HTML, CSS, and JavaScript.
It provides real-time weather information through API integration with a clean, interactive, and user-friendly interface.
🚀 Live Demo:
🔗 https://pavanibadi.github.io/WeatherSphere/
✨ Features:
 🔍 Search weather by city
 🌡️ Real-time temperature and weather conditions
 💧 Humidity, pressure, and wind speed
 🌅 Sunrise and sunset information
 🌬️ Air Quality Index (AQI)
 📊 Interactive weather charts
 ⭐ Favorites and recent searches
 📱 Fully responsive design
 🛠️ Technologies Used:
* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeatherMap API
* Chart.js
📂 Project Structure:
WeatherSphere/
├── index.html
├── style.css
├── script.js
└── README.md
💻 Installation
1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser, or run it using Live Server in Visual Studio Code.
